Sou estudante de **Engenharia de Software na UDF**, em Brasília-DF, e tenho interesse em desenvolvimento de software, programação e tecnologia.

Venho desenvolvendo meus conhecimentos em **Python, lógica de programação e desenvolvimento web**, utilizando projetos próprios para transformar o aprendizado em prática.

Durante minha trajetória, desenvolvi projetos envolvendo:

- Criação de páginas web com HTML, CSS e JavaScript.

API desenvolvida em Python que recebe uma conversa exportada do WhatsApp e disponibiliza estatísticas e gráficos a partir dos dados da conversa.

**Funcionalidades:**
- Recebimento de conversas exportadas do WhatsApp.
- Processamento e análise das informações.
- Geração de estatísticas sobre os dados.
- Visualização de informações por meio de gráficos.

### 3. Gerenciador de Finanças

Aplicação desenvolvida em Python para controle financeiro pelo terminal, permitindo registrar receitas e despesas e acompanhar o saldo.

**Funcionalidades:**
- Cadastro de receitas e despesas.
- Cálculo do saldo financeiro.
- Consulta de totais por categoria.
- Armazenamento de informações em arquivos JSON.
